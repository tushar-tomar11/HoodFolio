# HoodFolio documentation (VitePress)

Product docs site. Run locally:

```bash
pnpm install
pnpm dev
```

Opens [http://localhost:5174](http://localhost:5174).

Upstream rotki **Sphinx** developer docs remain in \`../docs/\`. This folder
is the HoodFolio user guide (sidebar, search, green theme).

Deploy: Vercel project with root directory \`docs-site/\` (see \`vercel.json\`).
