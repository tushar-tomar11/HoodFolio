# Supported Tokens

HoodFolio maps **10** equity-style tokens plus **USDG**.

| Symbol | Name | Decimals |
|--------|------|----------|
| TSLA | Tesla | 18 |
| NVDA | NVIDIA | 18 |
| AAPL | Apple | 18 |
| MSFT | Microsoft | 18 |
| AMZN | Amazon | 18 |
| GOOGL | Alphabet | 18 |
| META | Meta | 18 |
| COIN | Coinbase | 18 |
| SPY | S&P 500 ETF | 18 |
| QQQ | Nasdaq 100 ETF | 18 |
| USDG | USD Gold / Global Dollar | 6 |

Addresses are on [Token contract addresses](/stocks/contract-addresses).
Unmapped tokens do not appear in Portfolio even if you hold them.

To add a name, see [Adding stock tokens](/contributing/adding-tokens).
