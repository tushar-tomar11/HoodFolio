# Robinhood Chain Overview

Robinhood Chain is an **Arbitrum Orbit L2** (id **4663**) with ETH gas and
full EVM tooling. Tokenized stocks and USDG trade here 24/7.

HoodFolio is an independent AGPL dashboard for that chain. It is **not**
Robinhood Markets, not a broker, and not a custodian.

Learn the RPC table on [Network details](/robinhood-chain/network), then
[Connect a wallet](/getting-started/connect-wallet).
