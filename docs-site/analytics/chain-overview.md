# Chain Overview

The **Analytics** page and the Overview stat strip summarize DexPaprika
aggregates for network `robinhood`:

- Pool liquidity (TVL-style)
- 24h volume
- 24h transaction count
- Count of mapped stock tokens (local constant: 10)

If the API errors, use **Retry**. HoodFolio will not paint a fake $148M.

These figures describe **DEX activity**, not Robinhood Inc. brokerage volume.
