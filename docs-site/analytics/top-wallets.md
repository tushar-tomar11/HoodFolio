# Top Wallets

If HoodFolio shows large holders, they come from explorer or DexPaprika
holder endpoints — not from a private HoodFolio index. When the view is
unavailable, the page should say so instead of listing fictional whales.

HoodFolio still will not store those addresses on a HoodFolio server.
Treat any ranking as public-chain data that can lag.

For your own wallet, use [Portfolio](/portfolio/overview).
