# Meme Coin Leaderboard

The leaderboard is **volume-ranked pools / tokens** from DexPaprika on
Robinhood Chain. It is not an endorsement.

Memecoins can be ruggable. Stock tokens in HoodFolio's map are a separate
list. Do not assume a high-volume ticker is NVDA.

Cross-check the contract on [Blockscout](https://robinhoodchain.blockscout.com).
