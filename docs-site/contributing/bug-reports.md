# Bug Reports

Open an issue on GitHub with:

- URL / route (`/stocks`, `/portfolio`, …)
- Wallet connected or not
- Chain id shown in the navbar
- Whether DexPaprika or RPC failed (Retry visible?)
- Browser and a screenshot of the **non-inverted** UI

Security issues that could drain wallets should not be filed as public
"nice to have" tickets — HoodFolio is read-only, but Uniswap links still
deserve care.
