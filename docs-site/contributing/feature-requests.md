# Feature Requests

Good requests name the **data source** (viem, DexPaprika, Morpho, Blockscout)
and whether the feature stays **read-only**.

Out of scope unless you also design signing UX:

- In-app swaps
- Custodial accounts
- Tax lots / Form 8949
- Fake sparkline history presented as DexPaprika candles

Token listings: [Adding stock tokens](/contributing/adding-tokens).
