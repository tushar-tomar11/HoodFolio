# Contributing

HoodFolio is AGPL-3.0, forked from rotki. Product docs (this VitePress site)
live in `docs-site/`. The Vue app lives in `frontend/app/`.

Useful entry points:

- [Development setup](/contributing/dev-setup)
- [Bug reports](/contributing/bug-reports)
- [Feature requests](/contributing/feature-requests)
- [Adding stock tokens](/contributing/adding-tokens)

Please do not submit fake price fixtures as "product data." Tests may mock
DexPaprika; the running app must not.
